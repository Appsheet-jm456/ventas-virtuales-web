# Carpeta public

Aquí van los archivos estáticos que se sirven tal cual (imágenes, logo, favicon).

## Logo de la empresa

Sube tu logo con el nombre exacto **`logo.png`** en esta carpeta:

```
public/logo.png
```

- Formato recomendado: **PNG con fondo transparente**.
- Alto ideal: ~100–160 px (se ajusta solo en pantalla).
- Aparece automáticamente en el encabezado y en el pie de página.

Si el archivo no existe, la web muestra la marca de respaldo "VV" sin romperse.

Para usar otro nombre o formato (por ejemplo `logo.svg`), cambia el valor de
`logo` en `lib/site.js`.
